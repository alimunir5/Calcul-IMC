# Calcul IMC

Pour calculer ton IMC... et te faire juger au passage, cette petite app web en HTML, CSS et JavaScript situe ton résultat selon les tranches de l'OMS et l'accompagne d'un commentaire d'humour noir.

**👉 [Essayer l'app](https://alimunir5.github.io/Calcul-IMC/)**

Entre ton poids et ta taille : l'app calcule ton Indice de Masse Corporelle, te place sur une jauge, te donne la fourchette de poids « normal » pour ta taille et t'envoie un commentaire d'humour noir adapté à ta tranche.

## Lancer l'app

Aucune installation : ouvre `index.html` dans ton navigateur.

## Tranches (OMS)

| IMC | Catégorie |
| --- | --- |
| < 16,5 | Dénutrition |
| 16,5 – 18,5 | Maigreur |
| 18,5 – 25 | Normal |
| 25 – 30 | Surpoids |
| 30 – 35 | Obésité modérée |
| 35 – 40 | Obésité sévère |
| > 40 | Obésité morbide |

> L'IMC ne distingue pas le muscle de la graisse. Les commentaires sont de l'humour, pas un avis médical.
